🔥 Firestore 데이터 내보내기

원하는 컬렉션을 JSON 파일로 다운로드합니다.

사용 방법
  1. 본인 프로젝트의 firebaseConfig를 아래 칸에 붙여넣기
  2. 내보낼 컬렉션 이름을 입력하거나 칩에서 선택
  3. 내보내기 버튼 클릭 → JSON 파일 자동 다운로드
restaurants menus reviews tasteProfiles users activities blockedMenus

ℹ️ firebaseConfig는 공개돼도 안전합니다. 실제 보안은 Firestore 규칙에서 담당해요. "permission-denied" 에러가 뜨면 해당 컬렉션의 read 권한을 잠시 풀어주시고, 작업 후 원복하세요.
